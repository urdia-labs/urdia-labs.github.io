Privacy Policy

Effective date: September 28, 2026

1. Scope

This Privacy Policy explains how URDIA Labs handles information in connection with the URDIA desktop application and this public website.

2. Website

This website does not provide account registration, advertising, or embedded tracking tools. The site is hosted through GitHub Pages, and GitHub may process technical request data under its own privacy practices.

3. Desktop application

URDIA is designed as a local, desktop-first application. Project files, generated media, local databases and processing artifacts are intended to remain on the user's computer unless the user chooses to send content to a connected third-party service.

4. Platform connections

When a user explicitly connects a platform such as TikTok, URDIA may process the platform account identifier, basic profile information, access tokens and refresh tokens required to maintain the authorized connection. Tokens are stored locally using the Windows credential store/keyring where supported by the application.

5. Publishing

When a user initiates publication, URDIA sends the content and required metadata to the authorized third-party platform. URDIA does not claim ownership of that content. The third party processes the submission under its own terms and privacy policy.

6. Data minimization

URDIA requests only the permissions needed for the configured integration. The application is designed not to sell personal information and not to use platform credentials for advertising.

7. Retention and deletion

Local project data remains under the user's control on the user's computer. Platform authorization can be revoked by the user through the platform or by removing the connection from URDIA. Removing local application data can remove locally stored tokens and project records, subject to the operating system and application behavior.

8. Third-party services

Third-party APIs, hosting providers and AI/media providers have separate policies and terms. URDIA is not responsible for data practices outside its own application and website.

9. Contact

Questions about this policy can be directed to the URDIA Labs project through GitHub.

10. Changes

This policy may be updated when the product, integrations or applicable requirements change. The effective date above identifies the current version published on this site.
